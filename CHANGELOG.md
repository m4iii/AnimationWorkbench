# Changelog

## v0.0.1 — 2026-10-19

Initial public version.

- Local Python backend and self-contained browser workbench.
- Video, image sequence and atlas import with a shared frame timeline.
- Exact decoded-pixel grouping for image sequences and atlases; repeated frames remain visible.
- Shared compact reference numbers for duplicate frames, without changing source order or timing.
- Selection, hover thumbnails/highlighting, fit-to-view previews and workspace persistence.
- Atlas split settings, source preview and grid restored with saved workspaces.
- Explicit Codex prompt/image jobs, cancellation, task history and generated-result review.
- Synthetic public sample media, vendored Lucide license, regression tests and CI.

Animation export and automatic data retention are not implemented. Model features require the user's separately configured Codex environment.
